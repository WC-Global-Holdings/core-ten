# Core Ten

A 10-minute, back-safe core routine (McGill Big 3 + bridges + dead bugs) with a TV mode, animated 3D exercise guide, voice walkthrough and cross-device sync.

Live: https://wc-global-holdings.github.io/core-ten/

This repo holds only the built site, published automatically from the source repo:

- `index.html` — the whole app in one file (3D figure model inlined). Open it over https for "Add to Home Screen" to work.
- `core-ten-guide.pdf` — printable exercise guide (also linked from the app).
- `version.json` — build stamp the app checks for updates.

Progress and the family roster are stored in the browser; Settings → Sync keeps every device in step through a private GitHub Gist.
